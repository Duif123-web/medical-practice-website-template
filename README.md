# Medical Practice Website Template

A professional, responsive website template for medical clinics and healthcare practices.

## Features

- **Professional Design** - Clean, modern interface suitable for medical practices
- **Responsive Layout** - Works seamlessly on desktop, tablet, and mobile devices
- **Security Headers** - Includes CSP and other security best practices
- **WhatsApp Integration** - Direct appointment booking via WhatsApp
- **Accessibility Focused** - Semantic HTML and proper heading structure

## Sections

- **Header** - Eye-catching introduction with call-to-action
- **About Us** - Practice overview and mission
- **Services** - List of medical services offered
- **Contact** - Address, phone, and WhatsApp booking button
- **Footer** - Copyright and professional footer

## Quick Start

1. Clone the repository
2. Customize the content (clinic name, address, services, phone number)
3. Update the WhatsApp phone number in the contact section
4. Deploy to GitHub Pages, Netlify, Vercel, or your preferred hosting

## Customization

Edit these files to personalize for your clinic:

- `index.html` - Update clinic name, address, contact details
- `styles.css` - Modify colors and styling to match your branding

## Deployment

This template is deployed on GitHub Pages and is publicly accessible.

## Security

- Content Security Policy (CSP) enabled
- X-Frame-Options header set to DENY
- X-Content-Type-Options header set to nosniff
- Referrer-Policy set to no-referrer
